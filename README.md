# 🛠️ Embedded Systems Project

A collection of tasks and experiments from the **Embedded Systems** course, using:

- 🧠 **ESP32 DevKit v1**
- 🍓 **Raspberry Pi 4**

## 🚀 What’s Inside

This repository showcases practical exercises combining microcontroller programming and Linux-based embedded computing. Topics include:

- Sensor integration
- GPIO control and automation  
- Communication protocols (I2C, SPI, UART)  
- Networking and remote access  
- C/C++ implementations  

## 📦 Hardware Used

| Device          | Role                          |
|----------------|-------------------------------|
| ESP32 DevKit v1 | Microcontroller tasks         |
| Raspberry Pi 4 | Edge computing + coordination |
